# Scripts de Inicio y Parada

Scripts multiplataforma para construir la imagen Docker (`pm-kanban:latest`), ejecutar el contenedor (`pm-kanban-app`) en `http://localhost:8000` montando `data/` y `.env`, y detenerlo limpiamente.

## Archivos

- **Windows (PowerShell)**: `scripts/start.ps1` y `scripts/stop.ps1`
- **Windows (CMD)**: `scripts/start.bat` y `scripts/stop.bat`
- **macOS y Linux (Bash)**: `scripts/start.sh` y `scripts/stop.sh`
